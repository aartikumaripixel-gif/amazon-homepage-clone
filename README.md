# 🛒 Amazon Homepage Clone

A front-end clone of the Amazon shopping homepage built using HTML and CSS. This project recreates the basic layout and visual elements of an e-commerce website.

## ✨ Features

- Amazon-inspired navigation bar
- Search bar UI
- Category navigation menu
- Hero banner section
- Product category cards
- Responsive-style layout elements

## 🛠️ Technologies Used

- HTML5
- CSS3

## 🚀 How to Run

1. Clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
